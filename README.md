# AvirA Mono Extractor

Компаньон к AvirA Dumper Il2cpp, но для Mono-версии игры. Ищет игру, где есть
`Managed\Assembly-CSharp.dll` (например выделенный сервер SCPSL), гонит ее
через ilspycmd и собирает весь C# код в большие файлы-чанки с заголовками
`FILE:`. Формат чанков такой же, как в старом экспорте `dedic code scpsl`,
только файлы теперь `.cs`.

## Что на выходе

```
out\Extract_<Название игры>\
    <Название игры>_Part_1.cs, _Part_2.cs ...   весь код игры кусками по ~560 КБ
    Ilspy\<Assembly>\                            сырой проект ilspycmd, можно удалять
```

После завершения папку `Ilspy` можно просто снести, чанки уже готовы.

## Как пользоваться

Нужен Visual Studio 2022 с C++ и .NET SDK (для ilspycmd).

1. Собери `AviraMonoExtractor.sln`, выйдет `out\AviraMonoExtractor.exe`.
2. Запусти его. Экстрактор сам найдет Mono-игры среди Steam-библиотек.
   Игра одна: старт сразу. Игр несколько: выбери номер из списка.
3. Если ilspycmd не установлен, экстрактор сам предложит его поставить
   (обычный `dotnet tool install -g ilspycmd`, нужен интернет, ставим один раз).
   Он не гонится за самомой свежей версией: переберет список и поставит ту,
   что реально встанет на твоего dotnet.

Пример ручного запуска по пути:

```bat
out\AviraMonoExtractor.exe "C:\Program Files (x86)\Steam\steamapps\common\SCP Secret Laboratory Dedicated Server\SCPSL_Data\Managed"
```

Через sln или консоль:

```bat
msbuild AviraMonoExtractor.vcxproj /p:Configuration=Release /p:Platform=x64
```

## Аргументы

```
<путь>                Assembly-CSharp.dll, папка *_Data или папка Managed
-o,  --out <dir>      корень вывода, по умолчанию out\ экстрактора
-g,  --game <имя>     фильтр по имени игры при автопоиске
-r,  --root <dir>     дополнительная папка поиска, можно повторять
-a,  --asm <файл>     декомпилировать еще и эту dll из Managed, можно повторять
-i,  --ilspy <путь>   прямой путь к ilspycmd.exe
-p,  --partsize <KB>  лимит чанка в килобайтах, по умолчанию 560
-h,  --help           подсказка по аргументам
```

Пример с extras-сборкой и своим размером чанка:

```bat
out\AviraMonoExtractor.exe -a Assembly-CSharp-firstpass.dll -p 1024
```

## Формат чанков

Внутри каждого чанка перед каждым исходником стоит блок:

```
========================================
    FILE: <исходный путь из проекта ilspy>
========================================
```

Большие файлы перетекают через границу чанка без повторного заголовка,
это специально, чтобы куски оставались сплошным текстом для поиска.
Файлы в UTF-8, так что grep и любая читалка работают как ожидается.

## Примечание

- Код в стиле AvirA Dumper Il2cpp, структура та же: src, out, build.
- Сейчас декомпиляция полностью на ilspycmd. В планах второй этап: свой CIL
  парсер, чтобы отцепиться от зависимости. Пока не сделан.
- Папка результата всегда зовется `Extract_<Название игры>`.
